01

Rebuilt independently in September 2026 from a course topic.

From a class demo to one testable system

The earlier material duplicated tree logic across notebooks, mixed numeric and categorical split semantics, and exposed test error during parameter exploration. I rebuilt the project as a personal implementation with separate model, data, evaluation and Shiny layers.

The classifier searches every adjacent numeric threshold using cumulative class counts. For categorical predictors it evaluates unique subsets up to eight levels, then uses documented probability-ordered candidates for higher-cardinality multiclass features.

02

Mixed data types and missing values have explicit rules.

Classification behavior I can explain

Numeric missing values use a median learned from training data; categorical missing values use the training mode. An unseen category follows the child that received more training rows. Leaf size, split size, depth and minimum gain constraints are validated before growth.

Predictions expose both class labels and normalized probabilities. Tree text, per-feature weighted Gini reduction, confusion matrices and per-class precision, recall and F1 make the fitted behavior inspectable. Gini importance is presented as a split summary, not as causal evidence.

03

Three deterministic splits per dataset.

Held-out results and reference comparison

Each run keeps complete duplicate rows in one partition, stratifies approximately 60/20/20, and selects maximum depth from 2, 4, 6 and 8 using validation macro-F1. The test partition is absent from the tuning curve. Each selected model is serialized, reloaded and checked against its recorded test predictions.

04

Reproducible locally, with the limitations kept visible.

Run the experiment, inspect the boundary

The repository includes an RStudio project, a 33-package renv lockfile, local-data checksum manifest, scripted evaluation, exported configurations and a GitHub Actions workflow. The Shiny interface displays data quality, train/validation curves, final metrics, tree structure and downloadable experiment bundles.

The implementation covers classification trees and depth/sample stopping. It does not claim regression CART, cost-complexity pruning, random forests or a production ML service. High-cardinality multiclass categorical search is heuristic and the displayed test partition must be replaced if further tuning uses its results.
